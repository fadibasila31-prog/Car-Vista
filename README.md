# Car-Vista

Car-Vista is a web application for displaying and searching for vehicles.

## About the Project

Car-Vista was developed as a web development project using PHP and MySQL. The application allows users to view vehicle information and search for vehicles through a web interface.

## Technologies Used

- PHP
- MySQL
- HTML
- CSS
- WAMP

## Features

- Vehicle listing and display
- Vehicle search
- Database integration using MySQL
- Web-based user interface
- Backend functionality using PHP

## Project Structure

The project contains the frontend, backend PHP code, and MySQL database components required to run the application locally.

## Running the Project

To run the project locally:

1. Install [WAMP](https://www.wampserver.com/).
2. Clone or download this repository.
3. Place the project folder inside the WAMP `www` directory.
4. Start the Apache and MySQL services.
5. Import the project's MySQL database into phpMyAdmin.
6. Open the project in your browser through the local WAMP server.

## Project Purpose

This project was created to practice web development, PHP programming, database integration, and building a web application from frontend to backend.
